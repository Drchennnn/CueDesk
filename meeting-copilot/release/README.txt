MeetingCopilot 整合版
2026-11-18

完整解压到可写目录，双击“启动.cmd”。配置方法见同目录“配置指南.txt”。
运行环境面向 Windows 10/11 x64，已附带原应用的 Electron 运行程序。

已整合的功能
实时语音转录、文本问答、翻译、会话备忘与历史会话。
静默全屏截图、原生框选、多图暂存与一次发送。
动态视觉接口、顺序备用与笔试多模型同时回答。
笔试专用小窗、答案阅读排版、字号字体、滚动与复制。
快捷键录制、鼠标侧键、窗口移动缩放与透明度。
面试资料库、岗位切换、项目与技术资料检索、来源引用与资料状态。
可选向量检索、稠密与稀疏混合检索、重排和问题改写。
面试记录导出、回答与转录整理。
摄像头选择、自有 NVIDIA Maxine AR SDK 眼神矫正引擎、预览与诊断。

包内结构
app              已整合的应用和原有运行依赖。
app/resources/eye-contact/engine  EyeContactEngine.exe 与虚拟摄像头组件。
app/resources/tools/maxine-sdk.cjs  SDK 下载、校验与解包管理器，内置 GPU 资源清单。
app/resources/tools/maxine          官方 7-Zip 解包工具及许可。
config           空白配置模板及可选运行环境配置。
data             首次运行后保存当前便携版的配置、会话和本地索引。
rag              可选向量服务、依赖清单和配置脚本。
release-manifest.json  文件校验清单。

资料路径、个人资料、会话、模型名称、接口地址、代理和密钥均从空白开始。
截图问答和资料库初始关闭，麦克风与开机自启初始关闭。
默认直接进入主界面，通过齿轮进入设置。
后续自行选择供应商预设时，界面会填入该预设的示例地址和模型。

眼神矫正默认采用轻量发布。首次开启时自动识别显卡，下载对应的 NVIDIA AR SDK 包并校验解包。
首次下载约 1.3GB，成功后 SDK 缓存在 data/maxine-sdk，后续开启复用本地资源。
联网失败时按界面状态检查网络，再次开启即可重试。
整合版使用自带的 Electron 执行 SDK 管理器。个人目录和云端 API 配置从空白开始。
离线构建可使用 --include-sdk，将预先准备的 SDK DLL 和模型一并放入包中。

本版作为最初截图补丁版的完整交付替代。启动入口已统一到本目录。
原应用的历史安装记录仍可用于回退，当前便携版使用自己的 data 目录。
如果将已使用的文件夹发给其他人，请重新使用原始空白 ZIP。
Windows 加密的 API 密钥与当前用户和设备有关，换设备后请重新填写。

上游版本 0.2.0-beta.1，许可证见 LICENSE.MeetingCopilot.txt。
Electron 和 Chromium 的许可文件位于 app 目录。
