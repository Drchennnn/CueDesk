请将此目录中的 MeetingCopilot Maxine 眼神矫正模块集成到目标 Windows Electron 项目。

先检查引擎 C# 源码、build.ps1 与目标项目现有摄像头控制接口。
编译我们自己的 EyeContactEngine.exe。由该进程直接加载 NVIDIA AR SDK 的 nvARPose.dll、NVCVImage.dll，创建 GazeRedirection、配置模型与 CUDA stream，并通过 NvCVImage_Transfer → NvAR_Run → NvCVImage_Transfer 完成逐帧处理。
摄像头采集、像素布局归一化、Softcam 输出、模式切换和资源释放均采用本模块的源码实现。

默认构建轻量包，将自有引擎和 Softcam 放到 resources\eye-contact\engine\EyeContactEngine.exe、engine\softcam.dll。
SDK 管理器放到 resources\tools\maxine-sdk.cjs，使用其内置资源清单按显卡架构选择下载包。
官方 7-Zip 的 7z.exe、7z.dll 和 License.txt 放到 resources\tools\maxine\。
首次开启眼神矫正时自动下载、校验并解包 SDK 到 userData/maxine-sdk，界面显示下载、校验和解包状态。首次下载约 1.3GB，失败后可重试。
整合版使用自带 Electron 运行管理器；独立轻量模块启动脚本使用 Node.js 22 或更新版本。
显式 --include-sdk 构建离线包时，将 SDK 放到 resources\eye-contact\sdk 或独立包 runtime/sdk。
NVIDIA SDK DLL、models 与许可证使用同一完整版本，GPU 模型匹配实际显卡。
进程工作目录设为 SDK 目录，传入 --sdk-dir .，确保中文安装路径可用。

保留现有设置页与 IPC，使用 eye-contact.cjs 管理子进程。
输入设备与个人路径默认留空。默认启用眼神矫正、eyeSize 为 3、temporal 为 4294967295、lookAway 为 false。
支持 mode idle、mode passthrough、mode correct 与 stop。消费 ready、stats、status、error、stopped JSON 行。
主程序退出或管道关闭时清理摄像头、CUDA、SDK handle、GPU 图像、COM graph 与虚拟摄像头。
空闲时释放真实摄像头，有消费者连接时恢复。

Softcam 可用 register-softcam-user.ps1 完成当前用户注册，记录原有用户注册并提供 -Restore 恢复。
控制层读取HKCR合并视图。全系统注册可使用Windows管理员流程。
注册指向项目内softcam.dll，并通过实际取流进程的模块路径核对。
